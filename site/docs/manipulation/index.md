# Manipulation

Les opérations qui transforment un tableau de données : lire un fichier, ne garder que
certaines lignes, calculer une colonne, regrouper, relier deux tables.

Ce sont les gestes que l'on répète tous les jours, quelle que soit la suite du travail.
Un modèle statistique ou un tableau de bord repose entièrement sur eux, et une erreur
commise ici se propage sans jamais se signaler.

## Comment lire une page de concept

Chaque page traite une opération et suit le même plan : le problème concret que
l'opération résout, le code dans chaque langage, les pièges fréquents, puis un exercice.

Le code affiché provient de fichiers versionnés qui sont exécutés à chaque modification
du site. Leurs sorties sont comparées à un résultat de référence commun aux trois
langages. Un exemple faux ne peut donc pas rester en ligne.

## Les jeux de données

Trois jeux se succèdent au fil du chapitre, du plus simple au plus difficile.

Les premiers concepts utilisent les données Palmer Penguins : trois espèces de manchots
mesurées en Antarctique, un tableau propre et court, qui permet de se concentrer sur
l'opération elle-même.

Viennent ensuite les données Open Food Facts, renseignées par des contributeurs. Les
unités y sont incohérentes, des colonnes entières sont presque vides, et certaines
valeurs sont aberrantes. C'est l'occasion d'apprendre à nettoyer.

Les derniers concepts portent sur les accidents corporels de la circulation routière,
publiés par l'Observatoire national interministériel de la sécurité routière. Les
données y sont réparties sur quatre fichiers reliés par un identifiant d'accident, ce
qui rend les jointures indispensables plutôt que théoriques.
